# Software-Project-ex1

This is exercise no.1 in Software Project course in Tel Aviv University

It's a kind of a calculator.
Supported operations are:
    1 - Power Calculation
    2 - Prime Check
    3 - Palindrome Check

First, choose a number from 1-3;
For power calculation, enter 3 integers (base,exponent,modulu)
for prime check/palindrom check enter an integer.
